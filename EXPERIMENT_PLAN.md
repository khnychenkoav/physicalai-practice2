# Практика 2 — предварительный план

План записан 18 ноября 2026 до результатов полных запусков.
PandaPickCube, PPO, seed=1, 1001 итерация, baseline=4096 сред.
Одинаковый инференс — 10 эпизодов, seed 42–51, успех при расстоянии до цели менее 0.05 м.

| Запуск | Единственное изменение |
| --- | --- |
| baseline | Без изменения |
| num_envs_2048 | num_envs=2048 |
| box_target_strong | box_target=40.0 |
| qpos_strong | robot_target_qpos=30.0 |
| learning_rate_3e4 | initial learning_rate=0.0003 вместо 0.001 |

## Гипотеза самостоятельного эксперимента

Меняется только начальный learning_rate. Расписание adaptive сохраняется.
Ожидаю более медленный начальный рост mean_reward, конечную награду близкую к baseline или немного ниже и SR близкий к baseline, с возможным снижением при недостаточном обучении.
Меньший начальный шаг ограничивает ранние изменения политики. Адаптация по KL может затем сблизить learning rate, поэтому конечный эффект может быть слабым.
Один seed и десять эпизодов дают описательное сравнение, которого недостаточно для установления статистической значимости.

Результаты будут добавлены после реального обучения и инференса.
